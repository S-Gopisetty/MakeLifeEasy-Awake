# MakeLifeEasy Awake

Keeps a Windows PC awake. The screen stays on, and the mouse is nudged once a minute so status apps do not go idle.

## Run it

On Windows, in this folder:

```bash
python awake.py
```

Press Ctrl+C to stop. Sleep is turned back on when it stops.

This is Windows only. It does not need the internet while it runs.

Source: [utilFiles/awake.py](https://github.com/S-Gopisetty/utilFiles/blob/main/awake.py)
